How these responses were collected

Every response in this benchmark was produced by a human pasting a structured prompt into the free web chat interface of each service — chatgpt.com, claude.ai, gemini.google.com, kimi.moonshot.cn, grok.com, and the rest. No APIs, no harnesses, no automated scripts, no system-prompt overrides. One prompt per fresh chat. The human saved the reply verbatim, including formatting artifacts, refusals, and errors. This means the results reflect what a real person gets when they open these services in a browser and type a prompt — not what a tuned API integration produces.
